# Support

For usage questions, reproducible bugs, and feature proposals, use the repository's GitHub Issues templates.

Before opening an issue:

- confirm you are using the current default branch or latest release;
- run `GAM.cmd doctor --json` when the launcher/runtime is involved;
- include the Charterion version, Windows version, browser, and relevant logs;
- remove credentials, tokens, cookies, private repository URLs, and other secrets.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md) instead of public issue reporting.

Charterion is currently focused on ChatGPT Web at `chatgpt.com`; requests for unrelated model-provider APIs may be closed as out of scope.
