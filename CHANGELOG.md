# Changelog

All notable public releases of Charterion are documented here.

## v0.5.0 — 2026-08-31

### Highlights

- Persistent Agent identity with durable conversation rollover and browser-runtime authority.
- Exact single-task dispatch with typed completion policies and structured semantic results for non-code work.
- Durable TaskWorkspace authority with exact-base Git worktrees, leases, scoped capabilities, verified claims, and crash-convergent cleanup.
- Prompt dispatch backpressure, elastic trusted-idle worker lifecycle, and stuck-generation convergence that never blindly resends uncertain prompts.
- Company System Policy and deterministic Role Charters for governed multi-Agent engineering work.
- Parent/Candidate self-hosting isolation plus exact-SHA promotion authority, independent approval, self-approval rejection, parent-drift fail-closed behavior, replay convergence, and reject-preserve semantics.
- Recursive self-hosting release smoke added to `verify:full`, alongside control, evidence, Change Request, fleet, Native Host, runtime-install, and launcher smokes.
- Charterion public branding, Apache-2.0 licensing, 10-language README governance, and release packaging remain preserved on the promoted v0.5 line.

## v0.4.1 — 2026-08-31

### Highlights

- Public project identity renamed to **Charterion**.
- Durable local control plane for projects, leases, capabilities, evidence, reviews, merge queue, browser runtime, and Supervisor-managed workers.
- ChatGPT Web orchestration with persistent Role/Project bindings, task routing, semantic messaging, review loops, and crash-aware delivery recovery.
- Git Change Request workflow with exact-SHA review binding and independent integration observation.
- Unified human/agent launcher through `GAM`, `gamd`, and `gamctl`.
- Apache-2.0 licensing, multilingual README governance, checksummed release packaging, and Windows runtime packaging.

The documentation for each release describes the capabilities present on that exact release commit; experimental branches are not release claims.
